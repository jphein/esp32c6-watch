A whole smartwatch OS on a bare-metal microcontroller.

Open-source firmware for the Waveshare ESP32-C6-Touch-AMOLED-2.06 — a Slint UI with four themes, an ESP-NOW mesh, a creature that hops between boards, a self-updating two-watch fleet, push-to-talk voice, seven games, and a hardware pedometer. No RTOS beyond an async executor. No PSRAM. No cloud.

The gist

Rust on the wrist, straight to the metal.

The watch renders to an onboard CO5300 AMOLED over QSPI DMA and talks to a fleet of sibling boards directly over ESP-NOW — no router, no broker in the middle. That fleet is now literally two watches, each naming itself from its own efuse MAC and updating itself over the air. It is a hardware target of the smol mesh project and a port of the original waveshare-watch-rs from the ESP32-S3 to the C6.

What it does

A full watch, plus a mesh, plus a menagerie.

Everything below runs in a single no_std binary on one RISC-V core.

flagship · v0.8.4

The Fleet — two watches, self-updating

There are now two. Each derives a per-device sigil identity from its efuse MAC — eldritch-lantern (node 122) and mythic-throne (node 236) — so a watch names itself with no config to flash. MAC-derived mesh node ids de-collide on the wire, each watch gets its own MQTT client id, BLE sigil advert, and OTA topic (ota_push.sh --target <sigil>). The v0.8.4 release was the first to land on both watches fully zero-touch over the air — pushed, not plugged in.

flagship

The Mesh Familiar

One living creature inhabits exactly one board at a time. Pull the plug and it hops to a neighbour over the mesh and keeps living there — every other node shows a Weasley-clock pointer toward wherever it currently is. Exactly-one-holder arbitration, migration on loss, and orphan re-election, ported byte-for-byte from the smol fleet.

SMOLv1 ESP-NOW mesh

Routerless fleet networking with HELLO / ACK / TIME / CFG / RELAY frames. Loop-free time authority: the watch does its own NTP and both adopts time from and serves it to the fleet. Wire-compatible with the wider smol project.

shipped · v0.8.2

Aurora wake gesture hints

Wake the watch and a duo-tone aurora breathes across the edges — a soft teal-and-blue sweep that shows, without a word of text, which way the gestures go. It fades as you touch, so it teaches the first time and stays out of the way after. Tuned to the AMOLED's true blacks and every theme's accent pair, and it honours prefers-reduced-motion.

Slint watchface + 5 pages

A swipeable carousel — Clock, Sensors, System, Power, and Mesh — rendered by the Slint software renderer with persistent chrome (radio dots, battery pill, page dots).

Paged app launcher

A paged 3×3 grid — one section per page (AUDIO · GAMES · SYSTEM) that flips instantly instead of scrolling. Seven games and Settings run full-frame in embedded-graphics; Voice, Sound, WLED, Energy, Climate and the theme picker render as Slint overlays on the live shell. Every tile is one row in the app registry.

Hardware pedometer

Step counting runs on the QMI8658 IMU's dedicated pedometer engine — it keeps counting even while the rest of the IMU is idle, so steps survive sleep.

shipped · v0.8.5

BLE GATT · stable identity

A trouble-host GATT peripheral riding esp-radio's controller. Each watch now advertises a stable static-random address derived from its efuse MAC (D8:A3:16:…) instead of a fleet-shared constant — so HA / Bermuda room-tracking survives reboots and OTAs. The BLE-on toggle persists (config v4), and v0.8.7 fixed a light-sleep-with-BLE lockup by tick-idling AOD so adverts never stop.

WiFi + NTP

Station mode with time-shared radio bursts for NTP, then it drops association to free the PHY for the mesh. Radios are off at boot, toggled from the watchface.

Weather

Live conditions fetched over WiFi and folded onto the watchface line beside your step count.

MQTT → Home Assistant

Publishes typed entities into Home Assistant over MQTT — the primary telemetry and climate transport — using the same discovery conventions the smol fleet does. One device, many sensors, plus two-way climate setpoint control.

shipped · v0.8.3

Reliable zero-touch OTA

One-tap self-serve: the update button raises WiFi itself, pulls the new build over HTTP, and flips slots — no pre-connect needed. Zero-touch push: tools/ota_push.sh publishes a retained MQTT announce that a monotonic build gate accepts only if it's newer. v0.8.3 made it dependable — retry that survives link drops, mesh traffic suppressed during the flash so bandwidth goes to the download, and tightened stall margins. Both land in the A/B layout — flash ota_1 while running from ota_0, then flip, with rollback safety.

shipped · v0.12.1

The freezing, cured

Both watches started freezing, and the cause wasn't in our code: esp-radio 0.18's WiFi blob null-dereferences inside ppRxFragmentProc during scan and associate — a deterministic panic ~2.2 s into boot, 100% of the time, into a reboot loop (#61). Disabling AMPDU RX — the one aggregation knob 0.18 exposes — took the crash rate 100% to 0% on both watches with roaming intact. Cable-flashed, since crash-looping firmware can't update itself over the air.

shipped · v0.12.0

Unmissable

A ping you cannot miss (#58): the chime became a four-note rising major arpeggio, and the pulse now lands over framebuffer games — a ping suspends the running app, frees the ~51 KB framebuffer so the Slint pulse can composite, then re-launches it exactly where it was. Every ping leaves a timestamped card in the shade. Sound also got a volume you control (#59) — a level plus mute that every chime, beep and touch tick honours, a touch HUD, and hardware buttons you remap in Settings. A short press only acts if the screen was already bright, so a press in the dark just wakes the watch.

shipped · v0.11.0

The fleet greets by name

Press the hero button and the other watch knows. Additive mesh PING/PINGACK frames carry a sigil-identified greeting (#35): the receiver wakes from always-on, blooms a full-screen accent-ring pulse with the sender's name, and plays a rising two-tone chime — or chimes and drops a card in the notification shade if the panel is off or a game holds the framebuffer. Delivery is confirmed, and silence times out honestly at 2 s.

shipped · v0.10.1

Never write the slot you're running from

A watch bricked itself, and the reason is worth knowing. OTA slot selection trusted otadata — which records a boot request, not a boot fact. Stale otadata from the pre-6 MB layout made “the other slot” resolve to the partition the CPU was executing from, and a retained push announce did the rest (#55). The running slot now comes from the MMU — the physical flash page the CPU actually executes from — and every flash write is range-checked against a deny-list, with the range math host-tested against the exact incident vectors.

shipped · v0.10.0

Dead AP, live UI

The render loop no longer owns the radio. WiFi, OTA and scanning moved into a dedicated net_task that exclusively holds the controller — commands in, a snapshot out, a hold mask replacing the old per-tick re-raise scramble, and 2s/10s/60s/300s backoff. The number that matters, measured on glass while the access point was dead: worst frame 202 ms. The same outage used to freeze the watch for 15 seconds. A loop-budget rule — more than 10 ms of blocking in any arm is a bug — plus a per-arm watchdog keep it honest, and OTA now survives a mid-download reconnect.

shipped · v0.8.8

The fastpath release

Five stacked latency and freeze causes, run down by forensics and fixed. MQTT state arrivals now wake the render loop instead of waiting for the next idle tick; “Finding your room” no longer eats a 10 s backoff racing DHCP; presses while disconnected reject with a hint rather than silently replaying later; Energy only reads unreachable on a real offline LWT; and the config record is dual-slot mirrored so a freeze can't wipe creds, theme, or radio state.

shipped · v0.2.0

Slint UI shell

The whole shell now runs on Slint — the 5-page carousel + launcher, always-on display, and the Mesh Familiar creature. The software renderer streams 2-line RGB565 strips straight to panel GRAM, so the ~202 KB framebuffer left boot entirely (fixing the boot-OOM) and is allocated on demand only for full-frame games. Merged to main.

dev · available

defmt-rtt debug

Feature-gated defmt logging over an RTT channel (probe-rs) — wire-speed structured logs with no serial monitor. Opt-in at build time, off by default.

shipped · v0.7.0

Voice push-to-talk → live transcript

Hold the Voice tile and the watch streams 16 kHz mono PCM over WiFi to a LAN bridge → Azure Speech-to-Text, then paints the returned transcript back on the glass — verified end-to-end on-device. The stream only starts once WiFi + DHCP are up, so it can't deadlock.

shipped · v0.7.0

Mic capture · Sound app

Live capture for the Sound app's level meter and for voice input. The two MEMS mics feed a dedicated ES7210 4-channel ADC (I²C 0x40) — SDOUT1 reaches the SoC on GPIO21 over I²S RX, powered from the AXP2101 ALDO1 mic rail. An on-glass mic-gain stepper trims the input level. (The ES8311 handles playback only.)

shipped · v0.8.5

Sound is back — speaker SFX

The tricky part: the mic's clock master must never stop, or capture dies. So playback (#23) substitutes samples into the always-running silent-clock TX ring — audio_out::play_pcm() takes mono 16 kHz s16le, the amp (GPIO6) + ES8311 power up only while a clip plays, and pops are triple-guarded (synth ramps, driven-silence lead-in, tail pad). Capture is gated half-duplex during playback. Back to life: the Snake food beep and tap-clicks on launcher tiles + UPDATE FIRMWARE.

shipped · v0.7.0

Four-scheme theme system

Midnight, Paper, Amber and Violet — one Theme.scheme selector routes 18 palette tokens through every screen. Pick it on-glass from a live-swatch picker; the choice persists to flash and re-applies at boot. See all four faces →

shipped · v0.7.0

Plugin / app registry

A no_std app registry collapses each launcher app to a single row — one source of truth for name, icon, accent, section and dispatch (framebuffer vs. Slint overlay) instead of edits scattered across five files. The launcher, games and overlays are all data-driven from it.

shipped · v0.7.0

Home Assistant companion

A native HA integration (esp32c6_watch) adds an HTTP surface for climate + energy control and a media_player speaker entity — so tts.speak and HA automations can announce straight to the watch, which pulls the transcoded PCM over HTTP. Additive to the primary MQTT transport.

shipped · v0.8.7

Room-aware lights

Press the hero Lights button and the watch publishes an MQTT command; Home Assistant resolves which room the watch is in — from its stable BLE address via Bermuda presence — and toggles that room, echoing retained state back to the tile (#39). Control the light where you're standing, no room-picker. Field-tested; HA logic lives in watch_lights.yaml.

shipped · v0.8.0

Tactile pressed-state feedback

The board has no haptic motor, so every tap answers visually. A shared controls.slint library gives ~52 touch targets a bold, one-frame pressed state — per-scheme pressed tokens, no tweening, and a ≥44 px hit-area floor throughout. See the interaction design →

shipped · v0.8.0

Partial rendering v2

A vendored Slint software renderer flushes only the even-aligned dirty regions that actually changed, with a pair-exact flusher that keeps the RGB565 strip geometry clean. The UI stays snappy at 6–11 fps without the artifacts that sank the first attempt.

shipped · v0.8.0

Wrist-raise wake

Tilt-to-wake from the always-on display: a lightweight accel-poll detector reads the QMI8658 for a raise gesture and lifts the shell out of AOD — no IMU interrupt line needed. Plus IMU step-counter fixes and an AXP2101 charger profile (CV 4.1 V, CC 400 mA, 25 mA term).

shipped · v0.8.1

AOD light-sleep never-panic

The always-on display drops the core into light-sleep to save power — and that path could panic on a bad esp-hal RC_FAST clock reading. v0.8.1 calibrates the RC_FAST tick count and gates the sleep entry so it can never panic on a stray value. Caught in the field by the second watch — the fleet already earning its keep as its own test bench.

dev · v0.8.0

UI test automator

An opt-in serial debug console lets an agent drive and measure the live UI — tap coordinates, swipe, read back state and frame timings over the wire (tools/ui_test.py). Agent-driven UI testing without a camera on the glass.

Two 4 MB app slots let the watch download a new build into the idle slot over HTTP, verify it, and flip the boot pointer — the same OTA discipline as the wider smol fleet, on a chip with no room to spare.

The memory story

With no PSRAM, every byte counts. The Slint migration drops the boot framebuffer entirely: the software renderer streams two-line RGB565 strips (~1.6 KB) straight to panel GRAM, and full-frame embedded-graphics apps allocate the ~202 KB framebuffer on demand — freed the moment you swipe back to the shell.

Quickstart

Build & flash in one command.

Stable Rust with the RISC-V bare-metal target (pinned in rust-toolchain.toml) and espflash. WiFi/BLE are off at boot and toggled from the watchface.

esp32c6-watch — cargo run --release
# install the flash tool
cargo install espflash

# WiFi creds live only in your local .cargo/config.toml (gitignored)
cp .cargo/config.example.toml .cargo/config.toml
# then add under [env]:
#   WIFI_SSID = "YourNetwork"
#   WIFI_PASS = "YourPassword"

# build the release firmware
cargo build --release

# flash + monitor — the configured runner does this on `cargo run`
espflash flash --monitor --chip esp32c6 \
  target/riscv32imac-unknown-none-elf/release/esp32c6-watch
Standing on shoulders

Prior art & inspirations

This watch is a port with a lineage. It began as someone else's firmware and grew inside a mesh project that studied dozens of others. Everything that shaped it is credited here.

◆ The origin

infinition/waveshare-watch-rs

The original 100% Rust watch firmware, written by Fabien (infinition) for the ESP32-S3-Touch-AMOLED-2.06. This project is a direct port of it to the ESP32-C6 — reworked for a chip with no PSRAM (RGB332 framebuffer in SRAM), no SD slot, no TE pin, and a different GPIO map. Dual-licensed MIT OR Apache-2.0; deep thanks to the upstream author for the foundation.
